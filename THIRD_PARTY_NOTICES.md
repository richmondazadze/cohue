# Dependency and source notices

This repository has no chosen application redistribution license yet; it is marked private in package.json. Publishing source requires that eventual project license decision, which does not block shared foundation work. npm dependencies are governed by their own licenses; retain their shipped LICENSE/NOTICE/source-availability information when building distribution artifacts. This document is a navigation ledger, not a replacement for upstream license text or an assertion all transitive licenses were manually reviewed.

Runtime dependencies include Next/React/Tailwind/Zod/React Flow/Motion/Zustand/TanStack/Radix (MIT according to package metadata), Drizzle (Apache-2.0), pg (MIT) and ELK.js (EPL-2.0 with secondary-license metadata). See docs/research/implementation-dependency-evidence.json for exact installed version/license metadata and package-lock.json for all resolved transitive sources/integrities. For [ELK.js](https://github.com/kieler/elkjs/blob/master/LICENSE.md), preserve EPL/component notices and make its corresponding source available with a clear source URL/version when shipping its browser bundle; modifications require corresponding source handling. ELK is installed unmodified. Do not assume every graph dependency is MIT.

Frontend must carry OFL alongside production self-hosted fonts and any allowed conversion, preserve reserved-name/license conditions and not ship Newsreader as part of the approved sole-font UI.
