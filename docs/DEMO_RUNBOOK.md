## A. Real two-phone journey (counts as item 4 evidence)

People: organizer (laptop), Person B (phone, Spanish), Person C (phone, French), optionally Person D (phone, English) as the replacement.

1. Each phone: open cohue.tech → **Join the network**. Pick the profile language (es / fr / en), confirm one skill each (B: Design, C: Hardware, D: Hardware), set availability covering tomorrow afternoon, tick participation and discoverable. Optional: use the record button to dictate the description (voice → editable draft; nothing submits by itself).
2. Organizer laptop: **Join** with a Coordination skill, then **Start a mission**. Describe it in English (optional "draft from text"), keep requirements Design + Hardware, group size 3, tick **I will take part as a member**, keep the default window (tomorrow 09:00–21:00) → **Review requirements** → **Start discovery**.
3. Wait for **Review proposed groups** (live updates; no refresh). Open **Network map** and **Activity** briefly for the video. **Select this group & prepare invitations**.
4. For each invitee: **Show invitation link & QR** → scan on that person's phone → **Open my invitation** (the token leaves the URL). B reads the Spanish machine translation beside the binding English terms; organizer can approve it in the theater, then B taps Listen.
5. B **Accept these terms**. C **Decline** (optional reason). Watch the repair: **Review the repaired proposal** → wait until the new revision card shows → select again. B approves again (changed group = fresh consent); D accepts.
6. **Activate mission** (enabled only when everyone approved) → **Open Mission Room**: tasks, team, Brief (English original + es/fr drafts; organizer approves, members Listen), public resources marked unverified. Move one task to In progress.
7. Optional: **Replay** scrubber and Impact panel.

Record for evidence: device models, browsers, languages used, time, mission id from the URL, and anything that failed.
