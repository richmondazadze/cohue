## Additional locked dependency finding

[ELK.js](https://github.com/kieler/elkjs/blob/master/LICENSE.md) is not MIT. Registry metadata for 0.12.0 declares `EPL-2.0 OR GPL-3.0-or-later`; upstream license is EPL-2.0 with a secondary-license notice. Proposed path: retain ELK.js unmodified under EPL, include license and source-availability notices for the shipped component and verify its bundled third-party notices. Do not assume this licenses the entire application under GPL or permits dropping component obligations. This review identifies required handling, not a legal opinion.

## Compatibility and security gate

Observed candidates: Next 16.4.3, React/React DOM 19.3.1, Tailwind 4.3.3, @xyflow/react 12.12.0, ELK 0.12.0, Motion 14.6.0, Zustand 5.0.16, TanStack Query 5.104.5, Drizzle 0.45.4, Zod 4.6.7, Vitest 5.0.5 and Playwright 1.64.1. Versions are observations, not an installed or approved lockfile. Next remains on approved major 16. Published React peer ranges overlap for the proposed graph/motion/state packages. Mastra core 1.79.0 requires Node >=22.13 and accepts Zod 3.25 or 4; @mastra/libsql 1.27.0 declares compatible core range. Current OpenFlowKit declares Node >=22.22 and pins its own Zod override; do not inherit it.

Recommend a Vercel-supported Node 24 runtime after checking account availability, aligned local/CI/deployment, rather than using local Node 26 by accident. [Next installation requirements](https://nextjs.org/docs/app/getting-started/installation) specify Node >=20.9, but all selected tools must also fit. Select Radix packages per component rather than installing every primitive. Verify Tailwind PostCSS plugin, Drizzle migration tool/driver, React types, ElevenLabs SDK or direct HTTP adapter, and remaining tool versions together during authorized scaffolding. Do a clean install, build, typecheck, audit and browser smoke before declaring compatibility or security. No production dependency tree exists yet.

## Orchestration experiment result

See ORCHESTRATION_EVALUATION.md and research/orchestration-spike/results.txt. Mastra successfully persisted suspension, recovered it across process restart, remained suspended on false approval, and resumed with objective preserved. A deliberately minimal custom SQLite sample persisted an approval-waiting mission and conditionally activated once across separate processes and repeated resume. This supports keeping the PRD custom state machine baseline; it does not show Mastra is incapable or slower in production.
