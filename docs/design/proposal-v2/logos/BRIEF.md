# COHUE logo concept brief — selection checkpoint

User requested a logo alongside the recreated light design system. Exact name: COHUE. Audience: mission creators, consenting collaborators and HackTX judges. Adjectives: open, human, precise, capable, calm. Promise: from disconnected potential to agreed shared action. Uses: app header, mobile icon, favicon, presentation/video. Decision-maker: user. Assumptions: no existing logo equity, original geometric SVGs preferred, concept selection precedes final kit.

Category review: bundled library search across 81 productivity/collaboration marks found abstract/combination/letterform common, with blue/cyan and circles/radial forms frequent. Avoid generic AI sparkles, brains, atom orbits, handshake illustrations, rainbow people and linked-dot networks. Blue is an interaction color in the proposed UI; logo is judged in black first. Library trademarks are studied, never traced; no library source copied into original artwork. Reference shelf appears only in diagnostic test HTML, not product assets.

Word map: cohue → gathering → room / aperture; coordination → independent paths / meeting; human → distinct agency / open space; precision → consistent contour / grid; promise → together without erasing individuality.

Longlist, relative design judgment scored out of 25 (clarity/distinction/simplicity/relevance/small size):

1. Open C with a separate participant block in its aperture — letterform, 22.
2. Two bent paths end at a shared meeting point — abstract, 21.
3. Custom COHUE wordmark with open terminals and common rhythm — wordmark-led, 21.
4. Three upright gates share one baseline — abstract, 17; risks bar-chart reading.
5. Two offset speech apertures form a C — combination, 16; chat-app cliché.
6. A comma becomes a gathering point — punctuation, 15; weak name association.
7. A folded ribbon spells CH — monogram, 16; ambiguous letters.
8. A square “room” with three entrances — pictorial, 17; architecture-app resemblance.
9. A reciprocal loop with one deliberate break — abstract, 16; generic sync icon.
10. Five equal strokes expand into COHUE — wordmark, 15; readability risk.

Selected A–C explore letterform, abstract symbol and wordmark-led identity. A recommended: simplest connection to the name, strong aperture and compact use. Honest risks: C-plus-dot territory is crowded, B can read as a route/S, C's companion C is less distinctive on its own. No trademark clearance or global similarity guarantee. A professional trademark/reverse-image check remains necessary before a final public identity.

Construction: A uses concentric 96/56-radius C arcs with a 90-degree opening plus a detached square; B uses two 32-unit bent paths and a separate meeting square; C uses custom filled geometric C/O/H/U/E paths, no font dependency or copied outlines. Exploratory lockups use the same authored wordmark. Font licensing does not constrain these path-only marks; interface Space Grotesk retains OFL notices.

Iterations: v1 symbols rendered at 512px and inspected. C companion overflow was identified by svg_audit and visible render; v2 moves it fully inside the viewBox. A's detached block enlarged 34→38 units to strengthen 16px rendering; B's central block 40→44 and terminal gap adjusted to retain separation. v2 audit has no FAIL/WARN, only documented informational centering/size notes. Scores are script heuristics, not certification. A slightly rightward bounding box balances the heavier left curve. C companion is intentionally narrow because it retains the authored letter's proportion.
